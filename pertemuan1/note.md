# Pertemuan 1: Pengenalan Pemrograman Visual dan Instalasi Visual Studio & .NET

> Dokumentasi materi lengkap tersedia pada berkas [README.md](file:///d:/00.Kuliah%20TI/praktikum-pemrograman-visual/pertemuan1/README.md).

### Ringkasan Materi:
1. **Pemrograman Visual**: Pendekatan pengembangan perangkat lunak melalui manipulasi grafis komponen visual (*drag-and-drop*) yang terhubung dengan alur logika program.
2. **Karakteristik**: Representasi logika visual, perancangan antarmuka intuitif, dan *instant visual feedback* (WYSIWYG).
3. **Komponen Ekosistem**:
   - **Visual Basic (VB.NET)**: Bahasa pemrograman berbasis event dan objek dari Microsoft.
   - **Visual Studio**: IDE untuk merancang form, menulis kode logika, serta melakukan *debugging*.
   - **.NET**: Kerangka kerja runtime (CLR) dan pustaka standar (BCL) untuk mengeksekusi aplikasi.
